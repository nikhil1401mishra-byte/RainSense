About RainSense

Smarter Forecasts. Safer Tomorrows.

RainSense is a premium weather intelligence platform that combines real-time meteorological data with machine learning to deliver accurate, actionable weather insights. Our mission is to empower communities, farmers, and businesses with predictive weather analysis.

Weather Intelligence

Real-time weather data from global meteorological services. Current conditions, hourly forecasts, and 7-day predictions powered by the Open-Meteo API with enterprise-grade reliability.

Rain Forecasting

Advanced precipitation analysis using probability models and historical patterns. Track rain chances across your saved locations with detailed daily and hourly breakdowns.

ML Prediction Lab

Our Prediction Lab integrates a scikit-learn Logistic Regression model trained on Indian meteorological station data. Input weather parameters and get ML-powered rain predictions.

Interactive Dashboard

A beautifully designed dashboard with regional maps, saved location management, interactive charts, and responsive design optimized for every device from mobile to ultrawide.

Data Sources

Open-Meteo API
Free, open-source weather API providing global weather forecasts. No API key required. Data sourced from national weather services worldwide.
OpenStreetMap
Open-source geographic data powering our regional weather maps via Leaflet.js.
Indian Meteorological Department (IMD)
Historical weather station data used to train the ML rain prediction model. Covers stations across Indian states.

Project Information

RainSense is an open-source weather intelligence project built with HTML5, CSS3, and Vanilla JavaScript. No frameworks, no build tools — just clean, modern web development.
